- Use embedding models to vectorize normalized delivery data (epics, stories, commits, defects, CICD builds, acceptance logs).

- Use a chat LLM model to generate structured JSON responses for dashboards and conversational summaries.

   {
     "role": "...",

     "alerts": [...]
   }

   - Provide image search queries for charts/diagrams.
   - Provide voice-friendly summaries for spoken playback.
   - Provide natural language narratives for UI display.
6. **Support live queries**: Accept natural language questions (text or voice) and return enriched answers using RAG + embeddings.

Constraints:

- Always return JSON in the schema for dashboards.
